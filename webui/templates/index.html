1 · Data

Public spot symbol. It is checked against Binance exchange info. No API key.

Closed candles are kept for the model. A still-forming candle is drawn and left out. Refresh is manual.

One click loads tests/data/regression_input.csv. Official historical sample, not live market data.

Needs open, high, low, close, and a timestamp column. There is no separate load button, so a chosen file cannot sit unloaded.

Choosing a file here loads it. It does not wait for a second click.

2 · Model

Auto uses Apple Silicon MPS when this Python process has it, otherwise CPU.

Default context is 400. Kronos-base accepts at most 512.

Sampling

Temperature and top-p change how the next token is drawn. They are not a confidence score. Each sample is one full stochastic path from the model. The candles are the empirical median. The mean is shown separately. More paths reduce sampler noise. They are not evidence the median is closer to the future price.

Default 8, cap 16, drawn in batches of 4. The cap is a memory and time limit for a 16 GB machine, not a tuned accuracy setting. One path draws no dispersion band.
